# EC551 Logic Synthesis Engine

A Python tool that accepts Boolean SOP expressions or JSON combinational
circuits, generates a truth table, minimizes the logic, and generates
structural Verilog.

## Requirements and Usage

Requires Python 3. No additional Python packages are needed.

Run from the repository root:

```bash
python3 main.py inputs/simple_boolean.txt
python3 main.py inputs/simple_circuit.json
python3 main.py inputs/complex_circuit.json
```

Boolean input uses adjacent variables for AND, `+` for OR, and `'` for NOT.
For example: `AB+C'`. Variables are single letters.
Parenthesized input expressions are not supported.

The program prints:
- Canonical SOP and POS for the function and its inverse
- Minimized SOP and POS, with literal savings
- Prime implicant and essential prime implicant counts
- ON-set and OFF-set counts
- Estimated gate delay

It also writes:
- `output.csv`: truth table
- `generated.v`: structural Verilog with module name `synthesized_logic`

These output files are overwritten on each run.

## Architecture and Folder Structure

Both input parsers produce the same truth-table representation.
The minimizer operates on that table, and the Verilog generator translates
the selected binary terms into primitive gates and direct connections.

```text
main.py
fpga_top.v
inputs/
python/
    boolean_func.py
    graph_parser.py
    canonical.py
    count_terms.py
    truth_table_exporter.py
    minimization.py
    verilog_gen.py
    delay_estimate.py
```

## Minimization

Prime implicants are generated by repeated binary-term merging.
Essential prime implicants are selected by unique minterm coverage.
Remaining coverage is found by searching combinations of other prime
implicants.

The search minimizes the number of terms, then minimizes literals among
covers with that term count. It does not guarantee the globally smallest
literal count across larger covers.

## FPGA Deployment

`fpga_top.v` is a handwritten wrapper connecting the generated module’s
A–E inputs to five switches and its F output to an LED.

## Custom Features

1. Truth-table CSV export.
2. Basic gate-delay estimation.

The delay estimate assumes AND = 2 ns, OR = 2 ns, and NOT = 1 ns.
It adds an AND delay when at least one term exists, an OR delay when
multiple terms exist, and a NOT delay when any complemented literal exists.

This is a simplified estimate, not measured FPGA timing.
